### Другие зафиксированные ошибки и исправления

- «Sie fragt Lehrerin» — пропущен артикль.
- «Sie fragt der Lehrerin» — неверный падеж.
- «Sie fragt die Lehrerin» — правильно.
- «Ich kaufe jeden Tag das Brot» — принято как грамматически правильное; более естественный общий вариант: «Ich kaufe jeden Tag Brot».

## Обязательный порядок перед каждым занятием

1. Открыть репозиторий Deutsch на GitHub: https://github.com/oleksandrlvutin-cmd/Deutsch
2. Открыть файл `verbs_tracker.md` и прочитать его актуальное содержимое целиком.
3. Проверить все глаголы во всех разделах: выученные, изучаемые и сложные.
4. Сверить каждый планируемый новый глагол со всем словарём.
5. Предлагать только глаголы, которых ещё нет ни в одном разделе. Не выдавать записанные глаголы за новые.
6. Если GitHub недоступен или файл не удалось прочитать, не начинать новые слова наугад.
7. После занятия сохранить все новые слова, статусы, ответы, ошибки и исправления.
8. После обновления повторно открыть файл и проверить, что изменения действительно сохранены.

## Правила обучения и формат заданий

1. Учить до 10 новых глаголов за занятие, по одному за раз.
2. Сначала называть значение нового глагола только по-русски, например: «оплачивать».
3. Не произносить и не писать немецкий глагол заранее. Сообщать немецкую форму только если пользователь сам спросит, как это слово будет по-немецки.
4. После русского значения сразу давать одно короткое предложение на перевод.
5. Не писать каждый раз фразу «новый глагол» и не добавлять лишние вступления.
6. Не повторять уже освоенные глаголы как новые и не заставлять пользователя повторно выполнять задания на них.
7. Не показывать формы прошедшего времени и Partizip II, если пользователь сам об этом не попросит.
8. Задания формулировать на русском языке.
9. Не подсказывать готовый перевод до ответа пользователя.
10. Исправлять ошибки кратко и точно, затем дать возможность попробовать ещё раз.
11. Не перегружать объяснениями и не задавать лишних вопросов.
12. Сохранять не только выученные слова, но и все слова на повторение, неосвоенные слова, ответы пользователя, ошибки, исправления и результаты каждого упражнения.
13. Не удалять старые записи и не создавать дубликаты.
14. В разговоре не перепечатывать весь словарь без просьбы пользователя; достаточно кратко сообщать статус проверки GitHub.

### Дополнительные замечания по проверке

- Для «ждать» используется конструкция **warten auf + Akkusativ**: «Ich warte auf den Bus».
- Для «отвечать на вопрос» используется **auf eine/die Frage antworten**: «Ich antworte auf die Frage». Не следует объяснять это как обычный прямой Akkusativ без предлога.
- Для «звонить другу» в данном контексте естественно **jemanden anrufen**: «Ich rufe meinen Freund an».
- **helfen** требует Dativ: «Er hilft seinem Freund».
- В последнем ответе пользователя «Sie warte auf ihre Freundin» ошибка только в спряжении: «Sie wartet auf ihre Freundin».
